# 🌙 Distance-Celebration — Zero Distance Celebrations

> **Distance is a technicality.**  
> Distance-Celebration is a high-fidelity, private virtual space designed for couples in long-distance relationships to celebrate milestones, cultural festivals, and daily rituals together in real time.

## ✨ Core Features

- **State-Driven SPA**  
  Seamless, zero-refresh transitions powered by Framer Motion for a native-app experience.

- **Dynamic Ritual Rooms**  
  Purpose-built virtual environments for:
  - 💝 Valentine’s Week (Rose Day, Propose Day, etc.)
  - 🌙 Cultural Festivals (Karwa Chauth, Diwali, Teej)
  - 🎂 Personal Milestones (Birthdays, Anniversaries)

- **Social-First Authentication**  
  One-tap login using Google, Instagram, or Facebook — zero friction onboarding.

- **Premium UI / UX**  
  Dark-mode-first design with:
  - Pure black base `#000000`
  - Rose `#FF5885` for action glows
  - Glassmorphism accents and subtle motion cues

🧠 Design Philosophy

This Application is built on three core principles:

Presence over productivity – shared moments matter more than features

Emotion-driven UI – animation and color guide feeling, not distraction

Privacy by default – spaces are intimate, intentional, and ephemeral
